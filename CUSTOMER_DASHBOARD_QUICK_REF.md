# Customer Dashboard - Quick Reference Card

## 🚀 At a Glance

### ⌨️ Keyboard Shortcuts
```
Alt + M  →  Browse Menu
Alt + C  →  View Cart
Alt + T  →  Track Orders
Alt + H  →  Order History
```

### 🎨 Visual Features
- **40 floating particles** in background
- **Live clock** updating every second
- **Animated counters** for stats
- **Gradient cards** with hover effects
- **Glass morphism** design
- **Ripple effects** on buttons

### 🎯 Quick Actions (4 Cards)
1. **🍽️ Browse Menu** (Green) - Order food
2. **🛒 View Cart** (Cyan) - Check cart
3. **🚚 Track Orders** (Pink/Yellow) - Track delivery
4. **📜 Order History** (Soft) - Past orders

### 📊 Dashboard Sections

#### Left Side (Main)
- **Recent Orders** - Your latest orders with status
  - View details 👁️
  - Track delivery 🚚
  - Rate order ⭐

#### Right Side (Sidebar)
- **My Stats** (Purple) - Order count & spending
- **Your Favorites** (Pink) - Most ordered items
- **My Profile** (Cyan) - Account info & settings

#### Bottom (Conditional)
- **Recommendations** - Suggested items
- **Quick Reorder** - Reorder recent purchases

### 🔔 Smart Features
- **Auto-refresh** every 60 seconds (when active orders)
- **Loading states** on buttons
- **Success notifications** (top-right)
- **Scroll animations** as you browse

### 🎬 Animations
- Cards **fade in** on load
- Numbers **count up** from 0
- Elements **slide in** from sides
- Cards **lift up** on hover
- Buttons have **ripple effect**
