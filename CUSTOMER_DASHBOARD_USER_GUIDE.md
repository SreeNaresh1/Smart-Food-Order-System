# Customer Dashboard - User Guide

## 🎯 Quick Start Guide

Welcome to your enhanced customer dashboard! This guide will help you navigate and use all the exciting new features.

## 📱 Dashboard Overview

### Welcome Banner
- **Personalized greeting** with your first name
- **Live clock** showing current date and time (updates every second)
- **Role badge** displaying your account type
- **Auto-refresh button** (appears when you have active orders)

### Quick Actions (4 Cards)

#### 1. 🍽️ Browse Menu (Green Card)
- **Shortcut**: Alt + M
- Click "Order Now" to view the full menu
- Explore all available food items

#### 2. 🛒 View Cart (Cyan Card)
- **Shortcut**: Alt + C
- Click "Check Cart" to review your current cart
- Modify quantities or remove items

#### 3. 🚚 Track Orders (Pink/Yellow Card)
- **Shortcut**: Alt + T
- Click "Track Now" to see delivery status
- Real-time order tracking

#### 4. 📜 Order History (Soft Gradient Card)
- **Shortcut**: Alt + H
- Click "View All" to see past orders
- Access order details and receipts

## 📊 Main Dashboard Sections

### Recent Orders (Left Side - Large Section)

#### What You See:
- **Order number** (#12345)
- **Date and time** of order
- **Status badge** (color-coded):
  - 🟢 Green = Delivered
  - 🟡 Yellow = Pending
  - 🔵 Blue = In Progress
- **Total amount** paid
- **Action buttons**:
  - 👁️ View: See order details
  - 🚚 Track: Track delivery (for active orders)
  - ⭐ Rate: Leave feedback (for delivered orders)

#### Hover Effects:
- Orders slide to the right when you hover
- Color bar appears on the left

#### Empty State:
- If no orders: Shows "Browse Menu" button
- Bouncing shopping bag icon

### My Stats (Right Side - Purple Card)

#### Displays:
- **Total Orders**: Number count with animation
- **Total Spent**: Amount in rupees with animation

#### Features:
- Numbers **count up** from 0 to actual value on page load
- **Pulsing animation** for visual emphasis
- "Order History" button to view all orders

### Your Favorites (Right Side - Pink Card)

#### Shows:
- **Item name**
- **Order count** (how many times ordered)
- **Price** in rupees

#### Interaction:
- Hover over items for highlighting
- Slide animation on hover

*Note: Only appears if you have favorite items*

### My Profile (Right Side - Cyan Card)

#### Information:
- **Profile picture** (animated avatar)
- **Your name**
- **Member since** date
- **Email** address
- **Phone** number
- **Address** (partial)

#### Buttons:
- 📝 **Edit Profile**: Update your information
- 💬 **My Reviews**: View your feedback history

#### Hover Effect:
- Profile avatar scales and rotates slightly

## 🎁 Smart Recommendations

### Recommended for You

#### Features:
- **Based on order history**: Personalized suggestions
- **Product cards** with:
  - Food icon
  - Item name
  - Price
  - "Add to Cart" button

#### Add to Cart:
1. Click "Add to Cart" button
2. Button shows **loading spinner**
3. Success message appears (top-right notification)
4. Button shows **checkmark** and "Added!"
5. After 2 seconds, button reverts to normal

#### Card Effects:
- **Hover**: Card lifts up and rotates slightly
- **Ripple effect** on button click

*Note: Only appears if you have order history*

## 🔄 Quick Reorder

### Reorder Recent Purchases

#### What You See:
- **3 most recent orders**
- Order number and date
- Total amount
- "Reorder" button

#### How to Use:
1. Click "Reorder" on any card
2. View order details
3. Add items to cart again

#### Card Interaction:
- Border color changes on hover
- Card lifts slightly

*Note: Only appears if you have previous orders*

## 🎨 Visual Effects Guide

### Card Animations
- **On page load**: Cards fade in and slide up
- **On scroll**: Additional cards appear as you scroll down
- **Sequential timing**: Staggered for smooth experience

### Button Effects
- **Ripple effect**: Click creates expanding circle
- **Hover**: Button slightly enlarges
- **Active states**: Shows feedback during actions

### Status Indicators
- **Color-coded badges**: Quick visual status recognition
- **Icon indicators**: Calendar, phone, envelope icons
- **Loading states**: Spinner for processing actions

## ⚡ Smart Features

### Auto-Refresh (Active Orders)
- **Automatic**: Page refreshes every 60 seconds
- **Notification**: Warning appears before refresh
- **Manual refresh**: Click refresh button in welcome banner
- **Smart**: Only activates when you have active orders

### Live Clock
- **Real-time updates** every second
- **Full format**: Day, date, and time
- **Always visible** in welcome banner

### Animated Counters
- **On load**: Numbers count from 0 to actual value
- **Smooth**: 2-second animation
- **Currency formatting**: Automatic for money values

### Keyboard Shortcuts
Press **Alt** + letter for quick navigation:
- **M**: Browse Menu
- **C**: View Cart
- **T**: Track Orders
- **H**: Order History

## 🔔 Notification System

### Types of Notifications:

#### Success (Green)
- ✅ Item added to cart
- ✅ Action completed

#### Error (Red)
- ❌ Failed to add to cart
- ❌ Action failed

#### Info (Blue)
- ℹ️ Refreshing order status

### Notification Behavior:
- **Appears**: Top-right corner
- **Duration**: 3 seconds (auto-dismiss)
- **Interaction**: Click X to close manually
- **Animation**: Slides in from right, slides out when closing

## 🐛 Troubleshooting

### Issue: Animations not working
**Solution**: Refresh the page, ensure JavaScript is enabled

### Issue: Auto-refresh not working
**Solution**: Check if you have active orders, refresh manually

### Issue: Keyboard shortcuts not responding
**Solution**: Click on the page first, then try shortcuts

### Issue: Slow performance
**Solution**: Close other browser tabs, clear cache

### Issue: Notifications not appearing
**Solution**: Check browser notification settings, reload page
