# 🔐 ROLE ACCESS QUICK GUIDE
## 30-Second Reference Card

---

## 🎯 THE FOUR ROLES

```
🔴 ADMIN          = Everything, Everywhere, All at Once
🟡 SUPERVISOR     = My Branch, My Team, My Area  
🟢 EMPLOYEE       = My Tasks, My Orders, My Work
🔵 CUSTOMER       = My Orders, My Profile, My Feedback
```

---

## 📊 WHAT EACH ROLE CAN DO

### 🔴 ADMIN (100% Access)
✅ **Can Do EVERYTHING:**
- Create/delete any user
- Add/edit/delete menu items
- View/manage ALL orders
- Process refunds
- System settings
- Financial reports

❌ **Cannot Do:**
- Nothing - Full access

---

### 🟡 SUPERVISOR (60% Access)
✅ **Can Do:**
- Create Employee/Customer accounts
- Toggle menu availability
- View/manage orders **in my area**
- Assign deliveries **in my area**
- View branch reports
- Manage my team

❌ **Cannot Do:**
- Create Admin/Supervisor accounts
- Delete any users
- Change menu prices
- View other branches
- Process refunds
- Access financial reports
- System settings

---

### 🟢 EMPLOYEE (35% Access)
✅ **Can Do:**
- View orders **assigned to me**
- Update order status (Preparing → Ready)
- Update delivery status
- Mark cash received
- View my tasks
- View my performance

❌ **Cannot Do:**
- View other employees' orders
- Manage users
- Edit menu
- Assign tasks
- Cancel orders
- View financial data
- Access reports

---

### 🔵 CUSTOMER (25% Access)
✅ **Can Do:**
- Browse menu
- Place orders
- Track my orders
- Make payments
- Submit feedback
- View my history

❌ **Cannot Do:**
- View other customers' orders
- Edit menu items
- Access kitchen/delivery system
- Manage users
- View reports
- Cancel confirmed orders

---

## 🔍 QUICK ANSWERS

| Question | Answer |
|----------|--------|
| **Can Supervisor delete users?** | ❌ NO |
| **Can Supervisor see other branches?** | ❌ NO |
| **Can Employee see all orders?** | ❌ NO (only assigned) |
| **Can Employee edit menu?** | ❌ NO |
| **Can Customer cancel confirmed order?** | ❌ NO (only pending) |
| **Can Supervisor process refunds?** | ❌ NO (admin only) |
