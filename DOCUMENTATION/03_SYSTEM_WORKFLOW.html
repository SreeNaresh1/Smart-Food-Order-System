Step 1: User Access

User navigates to the login page (/login)

Step 2: Credential Entry

User enters either:

  • Username OR Email
  • Password

Step 3: Smart Detection

System automatically detects input type:

  • If input contains '@' → Search by email
  • If no '@' → Search by username (name field)

Step 4: Password Verification

System verifies password using scrypt hashing algorithm

Step 5: Session Creation

On successful authentication, system creates session with:

  • user_id
  • user_name
  • user_role

Step 6: Role-Based Redirect

User redirected to appropriate dashboard:

  • Admin → Admin Dashboard
  • Supervisor → Supervisor Dashboard
  • Employee → Employee Dashboard
  • Customer → Customer Dashboard

✅ Security Features:

  • Password hashing with scrypt algorithm
  • SQL injection protection via ORM
  • Session timeout (30 minutes)
  • Failed login attempt tracking

Phase 1: Menu Browsing

  • Browse available menu items
  • Filter by category, price, dietary preferences
  • View item details, images, descriptions

Phase 2: Cart Management

  • Add items to session-based cart
  • Update quantities
  • Remove unwanted items
  • View cart summary and total

Phase 3: Checkout Process

  • Enter/confirm delivery address
  • Provide contact information
  • Add special instructions (optional)
  • Select payment method

Phase 4: Order Confirmation

  • Review complete order details
  • Verify total amount
  • Place order (creates database record)
  • Receive order confirmation with ID

💡 Cart Features:

  • Session-based (no database until checkout)
  • Persists during browsing session
  • Real-time total calculation
  • Cleared after successful order placement

Order Status Progression:

  • PENDING → Order received, awaiting assignment
  • PREPARING → Being prepared in kitchen
  • READY → Ready for pickup/delivery
  • OUT FOR DELIVERY → In transit to customer
  • COMPLETED → Successfully delivered

⚠️ Important Notes:

  • Each status change is logged with timestamp
  • Customer receives real-time status updates
  • Supervisor can reassign orders if needed
  • Completed orders trigger feedback request
